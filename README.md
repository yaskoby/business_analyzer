# 業務プロセス分析AIアシスタント

## 概要
半導体設計における28年の業務改善経験を活かし、業務プロセスのミス発生ポイントをAIで自動分析するツール。

## 背景
過去のフォトマスクミス撲滅プロジェクトでの経験を元に、業務改善のノウハウをAI技術で再現可能にしました。

## 技術スタック
- **言語**: Python 3.13
- **AI API**: Claude API (Anthropic)
- **手法**: プロンプトエンジニアリング

## 主な機能
1. 業務プロセスの自動分析
2. 潜在的なミス発生ポイントの抽出
3. 実務で使えるチェックリストの自動生成
4. 具体的な業務改善提案

## 使い方

### 必要なもの
- Python 3.x
- Anthropic API Key

### セットアップ
```bash
pip install anthropic
```

### 実行
```bash
python business_analyzer.py
```

## 成果
- 業務フロー分析の自動化
- チェックリスト作成時間の大幅短縮
- 28年の業務知識をAI化し、再利用可能に
